Rumpus Golf · Golden thread · v2 — “late night lounge”

Turn any floor into a mini golf course.

The 18 screens of v1 plus Settings, Credits, What’s new and the obstacle flow (detect → correct → hidden ball / new object), restyled: a warm charcoal ground so the camera feed and the ball colors carry the room, mint for every “go” action, soft 16–28px corners, glass panels over the feed. Hints switch to Xbox glyphs the moment a controller is detected (tweak: Input mode).

Players · go · warn. No green ball (it’s the cup’s color).
Controller hints
AConfirm BBack XAlt / Undo YSecondary LBRBPrev / next ≡Menu / pause LStick · move
Glyphs appear only while a controller is connected (Gamepad API “connected” event); otherwise the same slots show keycaps. A small controller badge sits in every top bar.
Overflow rule
Grandma Josephine Okonkwo-BrightwaterText never wraps, clips or overlaps. Anything wider than its slot (names, hints, course titles) scrolls gently end-to-end and back, pausing at each end so it stays readable. Nothing gets an ellipsis.

Rules the UI relies on
Stroke = ball goes stopped → moving. Turn ends when it stops (2 cm / 0.5 s), then S12 wipes to the next player.
Holed = stopped inside the hole zone (v2 also checks height). Rolling through or bouncing off never counts.
Undo pops the last event within the current hole; Fix score edits totals directly and is logged.
Lost ball never blocks play; ambiguous re-appearance pauses to S09-style re-assignment.
Controller detected → glyph hints + focus ring moves with the left stick / d-pad; no controller → keycaps, mouse and touch. Both modes coexist; nothing is controller-only.
